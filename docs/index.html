Set up in five minutes

You'll need uv, Node.js 20+ and MetaTrader 5. Claude Desktop is optional, for the AI coach.

Install

git clone https://github.com/gillani-hello/ai-trading-journal.git
cd ai-trading-journal
uv sync
cd web && npm install && npm run build && cd ..

Connect MetaTrader 5

uv run tj install-ea

Then drag TradeJournalSync from Navigator › Expert Advisors onto any chart. It's read-only and never trades.

Open your journal

uv run tj serve        # http://127.0.0.1:8000

Connect Claude (optional)

uv run tj mcp-config --write-desktop

Restart Claude Desktop, then ask: "Do my weekly trading review."

FAQ

Is this trading journal really free?

Yes. It's MIT-licensed open source, with no subscription, trial or paywall. The AI coach uses the Claude plan you already have.

Does it work with my broker or prop-firm account?

If you can open the account in MetaTrader 5, yes: demo, live and challenge accounts, hedging or netting.

Does the Expert Advisor trade?

No. It only reads history and writes files to MT5's shared folder. It never places, modifies or closes trades.

Where is my data stored?

On your computer, in a local SQLite database. Nothing is uploaded.

Do I need an API key for the AI coach?

No. It runs in Claude Desktop or Claude Code on your normal Claude plan, connected via the Model Context Protocol (MCP).

Does it support MetaTrader 4?

Not yet. The export EA is MQL5; an MQL4 version is on the roadmap.
